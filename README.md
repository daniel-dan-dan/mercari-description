# メルカリ説明文AI生成

スマホで撮った古着の写真から、メルカリ出品用の説明文とMac自動入力用データをAI（Claude Sonnet 4）で生成するPWAアプリ。

## 特徴
- スマホでカメラロールから写真を複数枚選択
- Anthropic Claude APIで画像分析→ブランド・アイテム・サイズ・色・素材・状態を抽出
- カテゴリ別の採寸値をユーザーが入力
- 決まったテンプレートに沿って説明文を組み立て
- 商品の状態・販売価格を確認して、Mac自動入力用の下書き保存へ進む
- 写真編集（切り抜き合成、2枚合成、4枚合成）

## 使い方
1. 初回のみAnthropic APIキーを入力（端末内にのみ保存）
2. 写真を選ぶ（全体1枚＋タグ1枚以上推奨）
3. カテゴリを選択して採寸値を入力
4. 「説明文を生成」ボタン
5. 結果を確認・編集
6. 商品の状態・販売価格・下書き保存前チェックを確認
7. 「下書き保存（Mac自動入力）」を実行

## 構成
- 純粋なHTML/CSS/JS（ビルド不要）
- `index.html` / `app.js` / `styles.css` / `manifest.json`
- ホスト: GitHub Pages

## API料金目安

## 注意
- APIキーはlocalStorageに保存されます（同デバイス内のみ）
- 採寸値はAIに推測させず、必ず実測値を入力してください
- タグから読めない素材/サイズは `---` と表示されます
