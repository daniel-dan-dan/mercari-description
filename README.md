# メルカリ説明文AI生成

スマホで撮った古着の写真から、メルカリ出品用の説明文とMac自動入力用データをAIで生成するPWAアプリ。

## 特徴
- スマホでカメラロールから写真を複数枚選択
- Mac側の `mercari-auto` 経由でOpenAI APIへ画像を送り、ブランド・アイテム・サイズ・色・素材・状態を抽出
- カテゴリ別の採寸値をユーザーが入力
- 決まったテンプレートに沿って説明文を組み立て
- 商品の状態・販売価格を確認して、Mac自動入力用の下書き保存へ進む
- 写真編集（切り抜き合成、2枚合成、4枚合成）
- 相場リサーチ条件をMac側へ送り、夜間に売り切れ相場を自動調査

## 使い方
1. 初回のみGAS URLを入力（Mac側サービスURL取得用）
2. 写真を選ぶ（全体1枚＋タグ1枚以上推奨）
3. カテゴリを選択して採寸値を入力
4. 「説明文を生成」ボタン
5. 結果を確認・編集
6. 商品の状態・販売価格・下書き保存前チェックを確認
7. 「下書き保存（Mac自動入力）」を実行

## 相場リサーチ
1. 上部タブの「相場リサーチ」を開く
2. ブランド、ジャンル、対象、価格帯を入力
3. 「調査依頼を保存」を押す
4. Mac側の `mercari-auto` が毎日3:20に待機中の依頼を調査
5. 翌朝「結果を更新」を押すと、調査結果メモに反映される

購入・出品・コメント操作は行わず、売り切れ検索の価格帯、状態別傾向、高単価サンプル、仕入れ目線の所感だけを保存します。

## 構成
- 純粋なHTML/CSS/JS（ビルド不要）
- `index.html` / `app.js` / `styles.css` / `manifest.json`
- ホスト: GitHub Pages
- AI生成: `~/mercari-auto/server.py` の `/describe` がOpenAI APIを呼ぶ
- 相場リサーチ: `~/mercari-auto/research_runner.py` がメルカリ売り切れ検索を読み取り、`~/mercari-auto/data/` に結果を保存

## API料金目安
画像付きリクエストはOpenAI APIの利用量に応じて課金されます。モデルはMac側サービスの `OPENAI_MODEL` で変更できます。

## 注意
- OpenAI APIキーはスマホ側のlocalStorageには保存しません。Mac側サービスの `.env` に `OPENAI_API_KEY` として保存します
- 採寸値はAIに推測させず、必ず実測値を入力してください
- タグから読めない素材/サイズは `---` と表示されます
