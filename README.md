# メルカリ説明文AI生成

スマホで撮った古着や工具などの写真から、メルカリ出品用の説明文とMac自動入力用データをAIで生成するPWAアプリ。

## 特徴
- スマホでカメラロールから写真を複数枚選択
- Mac側の `mercari-auto` 経由でOpenAI APIへ画像を送り、ブランド・商品名・サイズ・色・素材や仕様・状態を抽出
- 対象を「メンズ」「レディース」「その他」から選択し、工具などアパレル以外も生成
- カテゴリ別の採寸値をユーザーが入力
- 決まったテンプレートに沿って説明文を組み立て
- 商品の状態・販売価格を確認して、Mac自動入力用の下書き保存へ進む
- 下書き前に在庫候補を手動選択し、出品確定後の在庫連携を準備
- 写真編集（切り抜き合成、2枚合成、4枚合成）
- 写真と採寸を複数商品分、一時保存してから後でAI生成
- 相場リサーチ条件をMac側へ送り、夜間に売り切れ相場を自動調査
- 価格改定画面で、いいね頻度に基づく価格維持・100円値下げ・大幅値下げ候補と根拠を確認
- 既存の100円自動値下げ設定も同じ画面で確認し、状態別に絞り込み

## 使い方
1. 初回のみGAS URLを入力（Mac側サービスURL取得用）
2. 写真を選ぶ（全体1枚＋タグ1枚以上推奨）
3. カテゴリを選択して採寸値を入力
4. 「説明文を生成」ボタン
5. 結果を確認・編集
6. 商品の状態・販売価格・下書き保存前チェックを確認
7. 必要な場合だけ「在庫から選ぶ」で対象在庫を手動選択
8. 「下書き保存（Mac自動入力）」を実行

在庫を選ばなくても従来どおり下書き保存できますが、その商品は自動在庫連携の
対象外です。商品名から在庫を自動選択することはありません。選択した在庫は商品ごとの
一時保存にも保持され、別の商品へ切り替えた時に引き継ぎません。

在庫候補は、端末接続コードで保護されたMacサービスを経由して取得します。
GASの認証情報はPWAへ返しません。Mac側は下書き前の出品中一覧を保存し、
ユーザーがメルカリで出品確定した後の「最新取得」で、新規商品がタイトル・価格ともに
完全一致した場合だけ在庫対応を登録します。候補が0件または複数件なら自動登録しません。

工具などアパレル以外では、対象の「その他」を選ぶとカテゴリも自動で「その他」へ切り替わります。縦・横・高さを入力でき、衣類向けのサイズ推定は行いません。現在の自動カテゴリ一覧はアパレル用のため、メルカリ詳細カテゴリは下書き保存後にメルカリ側で手動選択します。

## 一時保存
1. 写真を選び、カテゴリと採寸を入力する
2. 「一時保存して次の商品へ」を押す
3. 保存完了後に入力欄が空になったら、次の商品を続けて入力する
4. 画面上部の「一時保存トレイ」から商品を選び、「編集」または「AI生成」を押す

AI生成やMac接続に失敗しても、一時保存した写真と採寸は残り、あとから再実行できます。一時保存は現在の端末内に保存されるため、Safariの履歴やWebサイトデータを削除すると消えます。

Mac接続先は端末内にも一時記憶し、GASとの通信が一時的に失敗した場合は自動再試行します。AI生成通信が失敗した場合も、直前に表示していた商品名・説明文は消さずに戻します。

下書き保存では、写真送信に時間がかかる場合も最大2分待ち、通信中断時は同じ受付IDで1回だけ自動再送します。同じ受付IDを使うため、Mac側で受付済みだった場合も下書きが二重作成されません。2回とも通信が切れたあとに手動で押し直した場合も、商品内容が同じなら端末に残した受付IDを再利用します。受付後の進捗確認も一時的な通信切断なら3回まで自動再接続します。写真データが大きい場合は画質を大きく落とさない範囲で自動的に通信向けデータへ切り替えます。

商品名には、春夏・秋冬などの季節語や、カジュアル・ビジネス・フォーマル・セレモニーなどの着用場面・雰囲気語を入れません。AIが候補として返した場合や手入力された場合も、下書き保存前に自動で取り除きます。説明文では商品の特徴を伝えるため、必要に応じてこれらの言葉を使用します。

「ご覧いただきありがとうございます✨」の直後に入る訴求文は、意味の切れ目に読点を置いた2〜3文へ整えます。体言止めは多くても1文までとし、残りは自然な「です・ます」調にします。AIの出力に明らかな句読点抜けがある場合は、表示前にも補正します。

## 相場リサーチ
1. 上部タブの「相場リサーチ」を開く
2. 「検索対象」でブランド、カテゴリー、キーワードを入力
3. 「絞り込み」でサイズ、状態、価格帯など必要な条件を選ぶ
4. 「確認・保存」で内容を確認し、「調査依頼を保存」を押す
5. Mac側の `mercari-auto` が毎日3:20に待機中の依頼を調査
6. 翌朝「結果を更新」を押すと、調査結果メモに反映される

購入・出品・コメント操作は行わず、売り切れ検索の価格帯、状態別傾向、高単価サンプル、仕入れ目線の所感だけを保存します。

## 価格改定おすすめ / 100円値下げ
1. 上部タブの「価格改定」を開く
2. 「最新取得」を押す（メルカリから現在の商品一覧といいね情報を読み取るため、商品数により数分かかります）
3. 各商品のおすすめ、根拠、累計・24時間・72時間・7日間のいいね増加を確認する
4. 必要に応じて現在価格、下限価格、自動ON/OFFを確認する
5. 「すべて」「値下げ中のみ」「値下げなしのみ」から表示対象を選ぶ

下限価格と自動ON/OFFは、商品ごとに変更した時点でMac側へ自動保存されます。短時間に切り替え直した場合も、最後の状態を順番に保存します。商品カードの「保存中…」「保存済み」で状態を確認でき、「保存失敗」と表示された場合だけ「再保存」で全商品を再保存します。

毎日21:00の商品同期で、商品ページのいいね合計を日別履歴として35日分保存します。初回値は基準値として扱い、3日分たまるまでは原則「判定材料を収集中」です。仮の判定基準は次のとおりです。

- 出品3日以内、または24時間で2件以上増加: 価格維持・様子見
- 72時間で1件以上、または7日で2件以上増加: 100円値下げ
- 出品14日以上、7日間増加なし、最後の増加確認から7日以上、100円値下げ3回以上: 大幅値下げ候補
- 出品14日以上で累計いいね0件: 写真・商品名など出品内容を見直す

期間別の増加数は毎日21:00の観測値同士を比較するため、いいねが付いた正確な時刻ではありません。メルカリの表示差で出品日時を取得できない商品は、保存済みの最古の商品同期日時を出品日数の安全側の基準にします。

「最新取得」とおすすめは表示・情報更新専用で、販売価格は変更しません。「最新取得」で見つかった新規商品には、毎日21:00の同期と同じく、現在価格の7割を下限にした100円自動値下げ設定が自動保存されます。おすすめ価格が設定下限を下回る場合も案は表示し、利益確認の警告を添えます。

## 構成
- 純粋なHTML/CSS/JS（ビルド不要）
- `index.html` / `app.js` / `styles.css` / `manifest.json`
- ホスト: GitHub Pages
- AI生成: `~/mercari-auto/server.py` の `/describe` がOpenAI APIを呼ぶ
- 相場リサーチ: `~/mercari-auto/research_runner.py` がメルカリ売り切れ検索を読み取り、`~/mercari-auto/data/` に結果を保存

## API料金目安
画像付きリクエストはOpenAI APIの利用量に応じて課金されます。モデルはMac側サービスの `OPENAI_MODEL` で変更できます。

## 注意
- OpenAI APIキーはスマホ側のlocalStorageには保存しません。Mac側サービスの `.env` に `OPENAI_API_KEY` として保存します
- 採寸値はAIに推測させず、必ず実測値を入力してください
- タグから読めない素材/サイズは `---` と表示されます
