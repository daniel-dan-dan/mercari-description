# 写真の文字入れ（v20261026a）

写真を選び、「写真編集」→「文字入れ」から編集します。写真が1枚でも利用できます。

- 入れる文字は自由入力で、100文字まで。改行でき、長文は画像内に収まるよう折り返し・縮小します。
- 初期設定は左上の白文字＋黒ふち・斜体です。黒文字＋白ふち、赤文字＋白ふちも選べます。
- 大きさはスライダー、位置は写真上の文字をドラッグして変更します。「位置・ふちの太さ」で位置・ふち・斜体も調整できます。
- 「この写真に反映」で選択中の1枚だけ確定します。キャンセルは未確定の変更を破棄します。
- 元写真と文字を別に保持し、保存・再読込後も再編集できます。「文字を消す」を反映すると文字なしへ戻ります。
- 明るさを再調整した場合も文字を描き直します。合成は文字なしの素材で行い、合成後の写真へ文字を追加してください。

処理は端末内で完結します。追加のAI呼出し、フォント取得、写真の外部送信はありません。説明文生成に使う写真は文字なしを維持し、メルカリ下書きへ渡す写真は文字入りにします。通信量削減時の画像でも文字を保持します。

文字専用の情報は `textOverlay`、出品用画像は `listingBase64` / `listingBase64HQ` / `listingThumbnailBase64` に保存します。元写真を加工のたびに上書きせず、商品切替・写真順変更・古い画像読込後の確定を防止します。

検証: 全50ファイルの自動試験、10ファイルの構文確認、バックアップ復元、390/320px幅のブラウザを確認しました。架空の写真で追加・保存・再読込・キャンセル・ドラッグ・明るさ変更後の文字保持と1024pxの出品用画像を確認しています。実iPhoneと実商品のMac下書き作成は別確認です。
