# 説明文と文字入れの改善（v20261027b）

- 「その他」で生成する説明文は冒頭のフォロー割案内を省略し、「ご覧いただきありがとうございます✨」から始まります。メンズ・レディースは従来の案内を保持します。保存済みの説明文を自動で書き換える処理は追加しません。
- 文字入れ画面のプレビューと操作ヒントを設定のスクロール領域から分離しました。設定欄だけをスクロールでき、画像と確定・キャンセル操作は常に表示します。画面が低い場合はプレビューを小さくして設定欄を確保します。
- 既存50ファイルの回帰試験、10ファイルの構文確認とバックアップ復元に成功。その他のフォロー割除外とメンズ・レディースの保持も自動確認しています。
- 390×844 / 320×568のブラウザ画面で設定欄を上下へスクロールし、プレビュー位置が変わらないことと、文字サイズが即時反映されることを確認しました。実iPhoneと実商品の生成・下書き作成は別確認です。

追加の文字スタイルは比較用の提案段階です。今回の公開版は既存3スタイルを維持しています。
