白い細い毛足のカーペット、左上からの柔らかな自然光、左下／右上の自然なアイビー。平置き姿勢を保ち、元の商品のRGB・柄・縦横比を使って合成します。服の大きさ調整、元写真比較、手動の輪郭戻し／消去／Undo、先頭への別写真追加があり、元写真は残します。

- `vendor/onnxruntime/`: ONNX Runtime Web1.30.0、WASM／module、MITライセンス、配布元・検証情報。
- `tests/test_background_template.cjs`, `tests/test_background_fabric_recovery.cjs`: 組込み・保存経路・元写真保持・欠落補完の回帰。

## 復活するとき

1. 古いコミットまたは保管ファイルを別の作業用ディレクトリへ取り出し、現行アプリとの変更点を比較します。現行app.jsや全リポジトリを古い版で上書きしません。
2. 専用ファイルを戻し、UI／イベント／写真入力ロック／保存経路を現行コードに合わせて組み込みます。既存の写真データを消去する作業は不要です。
3. 同じ配信元のWorker／model／runtimeを使用し、写真や鍵を外部へ送信しません。WASMに必要な `wasm-unsafe-eval` だけをCSPに戻し、`unsafe-eval`／inline scriptは許可しません。
4. 初回取得は約21MB増えます。SW資産のMIMEと原子的インストール、版数・背景URLの更新、古い版を入力中に強制更新しない動作を維持します。
5. 専用2テストに加え現行の全チェックを実行し、実写真とスマホ幅のブラウザで、フード／ファー・元写真保持・追加順・保存再読込・オフライン・キャンセルを再確認します。公開後の版とファイルを読み戻します。

## 既知の制約

モデルは白いファー・薄い縁を欠落させ、小物を残すことがあります。g版では明るい中立色の背景を確認できる場合だけ、元の服につながる明確に暗い部分を最大32px近傍で補い、過大な補完を拒否します。背景と区別できない白い生地を推測で生成する機能ではありません。手動修正を残し、任意の写真で完全な切り抜きを保証しません。

g版は38本のチェック、実ダウン写真の390px／320pxブラウザ、通常／黒い服モード、保存再読込、公開版オフライン動作を確認済み。実iPhone実機と実商品のMac下書き送信は未検証です。ユーザーの実写真・画面キャプチャをリポジトリへ含めていません。

## 保存データの扱い

背景付き写真も通常のJPEG写真として保存されているため、撤去後も表示・明るさ編集・既存の下書き送信用データに使えます。撤去に伴うIndexedDB／localStorageの削除や移行は行いません。
