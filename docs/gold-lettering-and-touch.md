# 金ふちと指操作（v20261027c）

「写真編集」→「文字入れ」の「白＋金ふち」で、白い文字と控えめな光沢の金ふちを選べます。ふちは濃淡のある金色で描き、プレビューと出品用画像で同じ処理を使います。

写真上で1本指を文字に重ねて動かすと位置を移動できます。写真上に2本指を置いて広げると文字を大きく、狭めると小さくできます。左右・上下・文字サイズのバーは削除しました。「ふち・斜体」の「左上に戻す」は維持します。

指を離す途中で文字が飛ばないようにし、操作が中断された場合は指の追跡を解除します。大きさは従来の上限・下限内に収め、写真から文字が切れない配置を維持します。

金ふち、指で動かした位置と大きさは、写真ごとに保存・再編集できます。元写真と説明文生成用の画像はそのまま保持します。新しいAI呼出しや外部フォント取得はありません。

検証: 50テストファイル/10構文、変更前バックアップ復元、金ふちの180/640/1024/1080px描画、指移動・2点ピンチのサイズ上下限・片指を離した後の位置保持・中断・保存復元を確認。ブラウザの390×844と320×568で4スタイルとバー削除、保存再表示、1024pxの金ふち出力を確認しました。ピンチは模擬ポインターによる検証であり、実iPhoneの二本指操作と実商品の下書き作成は未確認です。
